# Canonical Investment Project Routing

The source of truth is the **current project**, not this GitHub repository.

- 00_Universal_Investment_Analysis_Framework.md: thesis, valuation, fundamental buy checklist.
- 01_Thailand_Investment_Second_Brain_v2.md: Thai stocks, REITs, infrastructure funds, distributions and THB context (replace with newer canonical owner if superseded).

- 03A_Essential_Strategy_Risk_Performance_Second_Brain(1).md: sizing, risk and basic performance metrics.

- 04_Dividend_Portfolio_Management_System.md: verify holdings, forward cashflows, regular versus special distributions, income concentration.
- Investment_Book_Library_Learning_Roadmap_v1.md and Quant_Backtesting_MA_MACD_Lab_Record_v1.md: education/exploratory learning, not trading evidence.

Always retrieve the present canonical document before declaring price, holding, income, distribution, return or tax values. User-provided ZIP/CSV with provenance is stronger evidence than remembered outputs. A watchlist is not an owned portfolio.

The upstream Research Agent controls workflow and plotting conventions but **never** replaces a project's market data. Do not store user account identifiers, private brokerage statements, positions or tax records in a public GitHub repository.
